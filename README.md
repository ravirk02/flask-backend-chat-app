# Sukuun – Backend (Python API)

This is the backend service for the Sukuun chat application, built using Python. It handles authentication, messaging APIs, and real-time communication.

---

## 🚀 Tech Stack

* Python (Flask / FastAPI)
* REST APIs / WebSockets
* Database (MongoDB / PostgreSQL)

---

## ✨ Features

* User Authentication APIs
* Chat & Messaging APIs
* Real-time Communication Support
